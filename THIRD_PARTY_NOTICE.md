# Third-party attribution

Convai Innovations created the Laya model and software. The base model and Laya runtime are separate upstream components with their own Apache License, Version 2.0 terms. Mini Intelligence downloads the base checkpoint from the Hugging Face model repository. This distribution includes only its own inference code, maintainer tools, prediction head and low-rank adaptation tensors. This notice describes the upstream components.
